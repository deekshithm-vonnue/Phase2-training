# Ticket Management API Documentation

This API manages ticketing workflows, allowing operations to retrieve, create, update, and delete support tasks.

## Base URL
```text
http://localhost:3000/tickets
```

---

## Endpoints Overview

### 1. Get All Tickets
Retrieves a list of tickets currently saved in the storage.

*   **HTTP Method**: `GET`
*   **Path**: `/`

#### Response Examples

**Success (`200 OK`)**
```json
[
  {
    "id": "aa4718bc-d053-41ec-9720-41d52c397f65",
    "title": "Create login page",
    "description": "Implement authentication form interface",
    "priority": "high",
    "status": "closed",
    "assignee": "none"
  }
]
```

---

### 2. Get Ticket by ID
Retrieves details for an individual ticket by providing its unique ID.

*   **HTTP Method**: `GET`
*   **Path**: `/:id`

#### Response Examples

**Success (`200 OK`)**
```json
{
  "id": "aa4718bc-d053-41ec-9720-41d52c397f65",
  "title": "Create login page",
  "description": "Implement authentication form interface",
  "priority": "high",
  "status": "closed",
  "assignee": "none"
}
```

**Error Case (`400 Bad Request`)**
```text
Task not found
```

---

### 3. Create Ticket
Validates incoming payload fields and generates a new record appended with an autogenerated UUID string.

*   **HTTP Method**: `POST`
*   **Path**: `/`
*   **Headers**: `Content-Type: application/json`

#### Request Body Schema
```json
{
  "title": "string (Required)",
  "description": "string (Required)",
  "priority": "string ('low' | 'medium' | 'high')",
  "status": "string ('open' | 'in-progress' | 'closed')"
}
```

#### Examples

**Valid Request Body**
```json
{
  "title": "Fix Navbar Bug",
  "description": "The dropdown layout alignment breaks on mobile viewport displays.",
  "priority": "medium",
  "status": "open"
}
```

**Success Response (`201 Created`)**
```text
Task created successfully
```

**Validation Error Response (`401 Unauthorized`)**
```text
Title field is missing
```

---

### 4. Update Ticket
Modifies target parameters (`assignee`, `status`, or both) on an existing record.

*   **HTTP Method**: `PUT`
*   **Path**: `/:id`
*   **Headers**: `Content-Type: application/json`

#### Request Body Schema
```json
{
  "assignee": "string (Optional)",
  "status": "string ('open' | 'in-progress' | 'closed') (Optional)"
}
```

#### Examples

**Valid Request Body**
```json
{
  "assignee": "Deekshith M",
  "status": "in-progress"
}
```

**Success Response (`200 OK`)**
```text
Successfuly updated
```

**Payload Missing Error (`400 Bad Request`)**
```text
Please provide an assignee or a status to update
```

**Invalid Parameters Error (`401 Unauthorized`)**
```text
status field is missing or invalid
```

---

### 5. Remove Ticket
Deletes an active record inside the datastore matching the corresponding ID.

*   **HTTP Method**: `DELETE`
*   **Path**: `/:id`

#### Response Examples

**Success (`200 OK`)**
```text
Task deleted successfully
```

**Error Case (`400 Bad Request`)**
```text
Deletion failed
```
