# Connecting PSQL with backend

## Installation

1. **Install drivers**

```
npm install pg && npm install -D @types/pg
```

2. **Install dotenv**

```
npm install dotenv
```

3. **Install nodemon**

```
npm install -D nodemon
```

- **Update package.json**

```
  "scripts": {
    "dev": "nodemon"
  },
```

- **RUN**

```
npm  run dev
``
```
